# HOW TO BUILD
- clone this repo with the following command:
  `git clone https://github.com/lollo0140/NiloAi/`

- download the gemma 4 model you wish to use and rename it 
  `gemma.gguf`

- put the downloaded gemma file in the `model` folder in the root of the project


- then run these following comands `dotnet restore` `dotnet build`
